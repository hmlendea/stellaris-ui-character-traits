## 🔎 What This Document Covers

This document describes how Universum Infinitum - Character Traits at https://github.com/hmlendea/stellaris-ui-character-traits manages personal data. It covers the application conduct and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 🏠 Self-Hosted Deployments

This project distributes a mod installed and operated locally alongside Stellaris; it does not operate a hosted instance. This notice covers the mod and project-maintainer-controlled behaviour. Each player or operator controls their game configuration, local files, logs, backups, access controls, preservation, and request handling unless the project directly controls those functions.

The mod consists of static character-trait definitions, localisation strings, and image assets. It has no mod-level telemetry, update checks, crash reports, email, authentication, reverse-proxy, object-storage, or monitoring integrations, and it sends no data from a local installation to project maintainers or external services. The game, launcher, operating system, and distribution platforms may have their own data practices outside this mod.

## 📥 Data We Handle

### Data Provided to the Application

- The mod does not request personal data. Stellaris uses game data to apply its leader-trait definitions; this mod does not use that data to identify a person.

### Data Generated or Collected by the Application

- The mod does not automatically generate or collect personal data.

### Data Received from Integrations

- The mod has no integrations that receive personal data.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- Apply the mod's leader-trait definitions for admirals, generals, governors, and rulers in Stellaris — game data used by the game; no personal data
- Display the mod's trait names, descriptions, and icons — static localisation and image assets; no personal data

## 🗄️ Storage, Retention, and Deletion

The mod's files are stored in the location selected by the player or operator when installing the mod. The project does not store personal data from players. The mod does not create personal-data records to retain or delete. Players control local game files and any game or launcher data; removing or disabling the mod is described in the [installation instructions](README.md#installation).

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer. Steam Workshop, Paradox Mods, Nexus Mods, and GitHub are distribution channels; interactions with those platforms happen separately from mod execution and are subject to each platform's own data practices.

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| None built into the mod | No external processing by the mod | No personal data transferred by the mod | Not applicable |

## ⚙️ User Controls and Requests

The following documented controls or request procedures are available:
- Disable the mod in the Stellaris launcher or remove it from the local mod installation — the project does not retain personal data to access, export, or delete.

## 🛡️ Data Protection and Security

The mod does not process personal data and therefore has no mod-level personal-data storage or security controls. Players and operators are responsible for keeping Stellaris and their systems updated and for protecting their accounts, local files, backups, access controls, network exposure, and any logs created by the game or launcher. No system can be guaranteed absolutely secure.

The original maintainers are not responsible for changes, modifications, or privacy issues introduced by downstream forks.

## 🔄 Document Changes

Update this document when application data processes, storage, integrations, or deployment responsibilities change. The current version is published at https://github.com/hmlendea/stellaris-ui-character-traits/blob/master/PRIVACY.md.

## 📬 Contact

For questions about application data handling, contact the project maintainers. For a self-hosted instance, contact the instance operator, unless the project explicitly manages the request. Include the mod version and relevant data flow in a [GitHub issue](https://github.com/hmlendea/stellaris-ui-character-traits/issues); do not send passwords, access tokens, or other secrets.
